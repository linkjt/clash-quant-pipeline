## The Premise
Clash Royale is a competative video game where players go head to head placing cards stragegically in order to try to destory the opponents princess and king towers. 
In clash royale, players can chose from 171 diffrent cards to build an 8 card deck. There are over 7.4 trillion possible deck combenation. None of them have winrates for today. The answer is to overthink it.
